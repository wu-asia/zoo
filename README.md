# 荒野驯旅（Wildbound Zoo）

一个零依赖、离线可运行的原创 2D 跑酷与动物园经营小游戏。核心循环为：出发跑酷 → 跃迁到新动物 → 驯服捕捉 → 获得金币 → 建设动物园 → 再次探索。

## 运行

直接用浏览器打开 `index.html` 即可运行。项目不依赖服务器、框架、第三方素材或线上 API；推荐用 VS Code Live Server 等静态服务器打开，以获得更好的模块加载兼容性。

## 操作

- `A` / `←`：向左移动
- `D` / `→`：向右移动
- `Space`：跳跃
- `E`：跃迁到附近动物
- `Esc`：暂停/继续

移动设备上有屏幕按键。

## 已实现内容

- 程序化草原赛道、障碍、难度递增
- 8 种原创命名和差异化技能的动物（首版完整循环可从 4 种起步并逐步解锁）
- 动物跃迁、慢动作反馈、驯服、重复驯服奖励与狂暴机制
- 多类障碍、跳跃与动物专属化解规则
- 动物园展示、游客收入、三级可升级设施
- 图鉴的发现/捕获状态
- `localStorage` 存储金币、图鉴、升级、最高距离和设置

## 源码结构

`src/config.js` 是集中配置；`animals.js` 维护动物数据；`game.js` 编排跑酷规则；`renderer.js` 使用 Canvas 绘制；`ui.js` 管理界面；`storage.js` 管理存档；`zoo.js` 管理动物园经济。所有视觉元素均为 Canvas/CSS 绘制，无外部游戏素材。
